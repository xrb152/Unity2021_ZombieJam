- 目标文件：`Assets/Art/TechArt/Textures/PolygonCity_Texture_01_A.png`（1024²，PolygonCity 城市道具图集，被 `GoblinWeapon_sign.mat` 等材质引用，僵尸手里的 STOP 牌也是它）。
- 替换清单：TAXI(橙)→出租车、P 停车牌→停、HOTDOG→热狗、车牌 4 行→京A·2086/沪B·5223/粤B·6639/津C·7204、POLICE→警察、AMBULANCE→救护车、WARNING CAUTION+SUBWAY ENTRANCE→警告+地铁入口、TAXI(深灰)→出租车、SYNTHY AVE→辛西大道、WELLINGTON ST→惠灵顿街、ATM→取款、PHONE→电话、CITY BUS STOP→公交车站、XXX→酒吧、GIVE WAY→让/行、DELI & PIZZA→熟食披萨(竖排)、CITY LIFE→城市生活、COMING SOON→即将开业。
- 技术要点（踩过的坑，脚本 `%TEMP%\wb_atlas_cn6.py`）：
  1. 图集里文字行 bbox 不能靠"底色众数+差异 mask"自动测——框一旦压到色块边界就会把相邻色块当文字，bbox 撑满全框。最终用**人工核对过的固定矩形**（在整图上画绿框目视校验）+ **整块填充底色** + 居中写字。
  2. 底色不能逐行取中值/众数：文字占比高的行会把文字色当底色，整块被涂成红/蓝。要**每块取一个采样点**（色块空白处）或用整块众数（取桶内真实均值）。
  3. `PIL.text()` 用 `anchor="mm"` 之后中文仍系统性偏下（约 0.2×字号），需 `cy -= size*0.22` 校正。
  4. 小字号中文不要加 stroke：41px 的「停」加 stroke=2 笔画糊成一团。规则改成 `stroke = 2 if H>=72 else 1 if H>=48 else 0`。
  5. 有复杂图形的块（CITY LIFE 的剪影）不能整块填色，改用"只擦白色像素（min(RGB)>=238）再填深蓝"。
  6. `key = r*100000 + g*1000 + b` 会冲突（r 需要 1e6），否则众数色分解出错、整块变紫。

- 未改：报纸/说明性抽象横线纹样、栏杆、色带、纯色块（本来就没有可读文字）。
