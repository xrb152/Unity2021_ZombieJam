## 卡牌立绘里烘焙的英文 STOP（补漏）

用户截图指出「搭车客」卡面上有英文。定位结果：**不是 UI 文本，是立绘 PNG 里画死的白字 "STOP"**（僵尸举着八角停车牌）。上一轮"僵尸立绘无文字"的结论是误判——当时只看整体，没放大牌面。

- 受影响文件（同一张画的两个尺寸）：
  - `Assets/Art/Sprites/Units/FullHeight/Hitchhiker_256x384.png`（卡牌/图鉴大图）
  - `Assets/Art/Sprites/Units/HalfHeight/Hitchhiker_256x256.png`（半身图）
- 其余 4 个僵尸立绘（Zombie / Armored / Brain_Thrower / Walking-coffin）复检确实无文字。
- 做法（脚本 `.workbuddy/tmp/fix_stop.py`，原图备份在 `.workbuddy/tmp/backup/`）：
  1. 用红色掩码（205,77,58）求八角牌包围盒；
  2. **逐行**取红色 x 的 min/max，内缩 3px 得到牌面内部跨度，把跨度内非红的亮像素填成牌面红 → 干净抹掉字且不伤外圈描边；
  3. 用 `msyhbd.ttc`（微软雅黑 Bold）居中重绘「停车」，字号按"两字总宽 ≈ 牌面宽 0.88"自动求解（FullHeight=50px，HalfHeight=45px）。
- 结果：牌面为白字「停车」，与原 STOP 视觉密度一致，无残留。
- 世界里的 3D 立体停车牌不受影响：材质 `GoblinWeapon_sign.mat` 用 `PolygonCity_Texture_01_A.png` 图集，图集早前已中文化（停 / 让行 / 出租车 / 警察…）。
- 改动只碰 PNG，不动 .meta，Unity 聚焦后自动重导入即可。

## 黑屏根因：OPS 混淆器改掉了 Unity 序列化引用的类名

抖音开发者工具日志症状（14:52 那次打包）：
- `The referenced script (Gameplay.Configs.Boosters.BoostersConfig) ... is missing!`
- `A scripted object (probably Gameplay.Configs.Zombies.ZombieData?) has a different serialization layout when loading. (Read 48 bytes but expected 100 bytes)`
- 屏幕全黑，Logo 之后进 Bootstrap 就卡死。

定位（`Assets/OPS/Obfuscator/Log/WebGL.txt`，27MB 混淆日志）：
- `[OPS.OBF] Obfuscated names: Of 185 Namespaces 77%, of 387 Types 81%, of 2302 Methods 62%, of 2165 Fields 33%`
- `Rename Type [[Assembly-CSharp] Gameplay.Configs.Zombies.ZombieData] to kd`
- `Rename Type Namespace [[...] Gameplay.Configs.Zombies.ZombieData] to <空>`
- `Rename Type [[Assembly-CSharp] Gameplay.Configs.Boosters.BoostersConfig] to ku`
- 而 `.asset` / `.prefab` 里的 `m_Script` 仍按 **原名 + 原命名空间** 查找，运行时找不到 → 变成空脚本 → 反序列化字节数对不上。
- 关键认识：`Obfuscate_Assembly_In_Assets_AssemblyDefinitionFiles=False` 只覆盖带 asmdef 的程序集；**游戏代码全在 Assembly-CSharp（Assets/Scripts 下只有 Utils 有 asmdef）**，所以上一轮的改动没救回这次构建。

处置：`Obfuscator_Settings.json` 三个装配开关全关
- `Obfuscate_Assembly_AssemblyCSharp = False`
- `Obfuscate_Assembly_AssemblyCSharpFirstPass = False`
- `Obfuscate_Assembly_In_Assets_AssemblyDefinitionFiles = False`（上一轮已改）

后续若要恢复混淆，必须同时满足：类名+命名空间保留给 MonoBehaviour / ScriptableObject、序列化字段名保留、UnityEvent/Animation 事件方法名保留；否则 prefab/scene/asset 一律断引用。
